# Taller Básico de Git y GitHub

Bienvenido al **Taller de Git y Scrum con IA**.

En este curso aprenderás los fundamentos necesarios para comenzar a trabajar con repositorios y colaborar en proyectos usando Git y GitHub.

---

# Contenido del Taller

Durante este taller realizarás las siguientes actividades:

## 1.- Clonar un repositorio

Aprenderás a copiar un repositorio remoto a tu computadora.

Comando:

```bash
git clone URL_DEL_REPOSITORIO
```

---

## 2.- Crear y subir un archivo

Crearás un archivo dentro del proyecto y subirás tus cambios.

Comandos:

```bash
git add .
git commit -m "Mi primer commit"
git push
```

---

## 3.- Crear una rama

Aprenderás a trabajar con ramas para desarrollar cambios sin afectar la rama principal.

Comando:

```bash
git checkout -b nombre-rama
```

---

## 4.- Crear un Pull Request (PR)

Subirás tu rama a GitHub y crearás un Pull Request para integrar tus cambios al repositorio principal.
