# Carpeta uploads

Esta carpeta se utiliza para almacenar los archivos que serán subidos durante el taller.

---

# ¿Qué debe hacerse aquí?

Dentro de esta carpeta cada estudiante deberá:

- Crear un archivo simple
- Modificar archivos si es necesario
- Subir los cambios al repositorio usando Git

---

# Ejemplo

Puedes crear un archivo de prueba como:

```bash
archivo.txt
```

O también:

```bash
mi-practica.txt
```

---

# Flujo de trabajo

1. Crear un archivo dentro de la carpeta `uploads`
2. Guardar los cambios
3. Ejecutar:

```bash
git add .
git commit -m "Agregando archivo en uploads"
git push
```

---

# Recomendaciones

- No eliminar archivos de otros compañeros
- Usar nombres claros para los archivos
- Verificar los cambios antes de hacer commit

---

# Objetivo

Practicar el flujo básico de trabajo con Git y GitHub mediante la subida de archivos al repositorio.
